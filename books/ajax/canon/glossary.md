# Canon: glossary

For glossing Storr's English and the names. Gloss lightly: a word in passing,
never a list before a speech.

| Word | Means |
|---|---|
| anon | soon, presently |
| behest, hest | command |
| betimes | early |
| chid | scolded |
| coign of vantage | a good position to watch or strike from |
| corse | corpse |
| despite (noun) | contempt, scorn |
| eld | old age |
| enow | enough |
| erst | formerly, once |
| fain | glad, willing; gladly |
| forsooth | indeed (usually mocking) |
| guerdon, meed | reward |
| hanselled | used for the first time |
| hap, haply | chance; perhaps |
| harness | armour |
| leal | loyal |
| liefer | rather |
| methinks | it seems to me |
| moil | toil, drudgery |
| ope | open |
| rede | advice |
| ruth | pity |
| sirrah | form of address to an inferior; an insult between equals |
| sooth | truth |
| spoor | track, trail |
| stour | tumult of battle |
| targe | shield |
| trow, wot | believe; know |
| twain | two |
| whelm | overwhelm, drown |
| wight | person |

## Names and allusions

| In the text | Who or what |
|---|---|
| son of Laertes | Odysseus |
| race of Sisyphus | Odysseus again, as an insult: rumour made the trickster Sisyphus his real father |
| the Atridae, sons of Atreus | Agamemnon and Menelaus |
| son of Telamon | Ajax (also Teucer) |
| son of Thestor, the seer | Calchas, prophet of the Greek army |
| Eriboea | Ajax's mother |
| Erinys, Erinyes | the Furies, who pursue wrongs done within a family or against an oath |
| Hades | the land of the dead, and its god |
| Hermes | here as the guide of souls to the underworld |
| Erechtheus | legendary king of Athens; "sons of Erechtheus" are Athenians |
| Tauric Artemis | Artemis as a sender of madness |
| Cyllene | mountain in Arcadia, home of Pan |
| Sunium | the southern cape of Attica, the first sight of home for a ship bound for Athens |
| Scamander, Ida | the river and the mountain of Troy |
| Tyrrhenian trumpet | Etruscan war trumpet, proverbially loud |
| Pelops, Atreus | Agamemnon's grandfather and father; Teucer throws their crimes back at him in scene 10 |
