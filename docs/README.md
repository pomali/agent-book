# Docs

How these books work and how to make one.

| File | Read it when |
|---|---|
| [concept.md](concept.md) | You want the idea: what changes when the reader has an agent. |
| [format.md](format.md) | You need the rules: directory layout, manifest, parts, canon, studio briefs, reader state. |
| [authoring.md](authoring.md) | You are writing a book, alone or with an agent. Step by step, with checklists. |
| [ideas.md](ideas.md) | You want to push the experiment further. Open ideas and open questions. |

The three books in `books/` are the reference implementations: one mostly
seeds over a canon of facts (*Hold Fast*), one original fiction with a fixed
arc (*The Unploughed Strip*), and one existing public-domain text delivered
unaltered (*Ajax*). When the docs and
the books disagree, that is a bug; fix whichever is wrong.
